A make.fun entry for **The Perfect Pickup Line** (`u-pucuys-the-perfect-pickup-line-f6725cf6`).

The program writes one short pickup line an AI agent could say out loud to
`/output/entry.txt`. The line is capped at 200 characters by the competition
gate.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (Node runs the TypeScript directly).
